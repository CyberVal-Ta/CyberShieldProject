Attack Techniques Reference

Grouped by phase of an intrusion. This mirrors the structure of the MITRE ATT&CK framework its a public knowledge base of real adversary behaviour. Everything below is high-level and defensive in intent.

Phase Technique Description
Reconnaissance OSINT gathering Collecting public information about a target from open sources.
Reconnaissance Subdomain enumeration Discovering subdomains that may expose additional services.
Initial Access Phishing Delivering a malicious link or attachment via email to gain a foothold.
Initial Access Exploiting public-facing applications Abusing a vulnerability in an internet-exposed service.
Execution Command and scripting interpreters Abusing legitimate shells (bash, PowerShell) to run attacker code.
Persistence Scheduled tasks Registering a task or cron job that survives reboot.
Privilege Escalation Misconfigured permissions Abusing weak file or service permissions to gain higher rights.
Defense Evasion Obfuscation Encoding or hiding code so that it is harder to detect.
Credential Access Brute force Repeatedly guessing credentials against a service.
Lateral Movement Remote services Using legitimate remote-access protocols to move between hosts.
Exfiltration Exfiltration over web service Sending stolen data out through a normal web channel.
Impact Data encrypted for impact Ransomware: encrypting data to disrupt the target.

Source: MITRE ATT&CK (public framework). Descriptions written by me.
