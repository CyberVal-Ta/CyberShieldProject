# CyberShield

A personal study console for offensive and defensive security.
Built as a solo Git practical project and kept as a portfolio piece.

## Pages

- `index.html` — Home
- `techniques.html` — Reference list of attack techniques (MITRE ATT&CK style)
- `tools.html` — Four browser-based helpers
- `notes.html` — Glossary of red team concepts

## Tools

- **Password Strength Checker** — heuristic scoring against common patterns
- **Phishing Email Scanner** — keyword and pattern detection
- **IP / URL Security Checker** — static analysis of addresses and domains
- **Malware Analysis Simulator** — canned static-analysis report for demo purposes

Everything runs client-side. No external APIs, no tracking, no dependencies.

## Tech

- HTML5, CSS3, vanilla JavaScript
- No build tools
- Open `index.html` in any browser

## Disclaimer

All content is educational. No real systems are monitored or targeted.
The malware analysis simulator does not process real files.
