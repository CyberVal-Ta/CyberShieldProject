# CyberShield

A cybersecurity risk & threat awareness dashboard — simulated SOC interface built as a solo Git practical.

## Features

- **Password Strength Checker** — scores a password's resilience
- **Phishing Email Detector** — flags common phishing indicators
- **Incident Reports** — table of simulated security incidents
- **Awareness** — practical security tips
- **Live Activity Feed** — simulated SOC log stream on the homepage

## Tech

- HTML5, CSS3, vanilla JavaScript
- No build tools, no dependencies — open `index.html` in a browser

## Structure

    cybershield/
    ├── index.html          Home / SOC dashboard
    ├── password.html       Password strength checker
    ├── phishing.html       Phishing email detector
    ├── incidents.html      Simulated incident table
    ├── awareness.html      Security awareness tips
    ├── leader.html         Git practical artefact (Activity 3)
    ├── style.css           Full theme
    └── script.js           Page logic + live feed

## Git Practical Coverage

| Activity | Demonstrated |
|---|---|
| 1 | Repo init, remote association |
| 2 | Clone and sync |
| 3 | Feature branches, merge |
| 4 | Amend, revert, reset, checkout hash |
| 5 | Rebase with conflict resolution |

## Disclaimer

All data and "incidents" shown are **simulated** and for educational purposes only.
No real security tooling or offensive capability is included.
