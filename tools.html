Password Strength Checker

Type a password to see how it scores against common attack patterns. Nothing is sent anywhere — this runs entirely in your browser.

Start typing to see a score.

Phishing Email Scanner

Paste the contents of a suspicious email. The scanner looks for common indicators: urgency language, suspicious links, requests to verify accounts, and so on.

IP / URL Security Checker

Enter an IP address or a URL. The checker performs static analysis in your browser: it identifies the type of address, flags suspicious patterns, and gives a rough risk rating. No external requests are made.

Malware Analysis Simulator

Paste a suspicious filename or a fake MD5/SHA-256 hash. The simulator produces a canned analysis report — file type guess, entropy, common indicators, and a family profile. No files are executed and no real malware is involved. This is an educational demo of what a static analysis report looks like.
