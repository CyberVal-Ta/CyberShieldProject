About This Console

CyberShield is my personal study console for offensive and defensive security. It collects reference material, small browser-based helpers, and notes from my own learning.

Everything here is either public knowledge or written by me. No real systems are targeted. All examples are educational.

Built as a Git practical project and kept as a portfolio piece.

What's Inside

  • Techniques — reference list of common attack techniques, grouped by category, with short descriptions.
  • Tools — browser-based helpers: password strength checker, phishing scanner, encoder/decoder, hash identifier.
  • Notes — short glossary and study notes on red team concepts.
