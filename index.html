What This Console Is For

This is an internal tool for a fictional healthcare organisation. It exists so staff and the security team can answer three questions quickly:

  1. Is anything wrong right now?
  2. Can I safely use this password / trust this email?
  3. What does a real attack look like so I can spot one?
